# oco

oco 是一个以 OpenCode 为执行引擎的 VS Code 扩展。

产品形态：左侧管理会话和 Agent，在 VS Code 编辑器标签页中进行对话，通过设置和管理入口配置工作流。首选路线是 **VS Code 原生外壳 + 复用官方对话源码 + 有边界的宿主适配**。

当前状态：**开发计划已建立，尚未创建扩展代码、完成技术原型或验证运行效果。**
