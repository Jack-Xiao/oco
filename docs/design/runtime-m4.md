# 运行视图 M4：回放播放、日志、回环航道（设计定稿 2026-10-04）

来源：用户对 M3 运行视图的反馈与多轮示意图评审（本文件只记已定决定，不含讨论过程）。
约束：外层框架（顶栏 / 中部左栏 + 右侧 / 日志行 / 状态栏）的网格不变，所有改动只发生在各框内部。

## 第一批：只改界面，不动数据模型

### 1. 回放播放控制（顶栏右侧，保持一行）

- 控件：`[实时 | 回放]  ⏮  ◀  ▶/⏸  ▶|  进度条  n/N  1×`。进度条从 `w-36` 缩到约 `w-28`，为按钮腾宽度。
- 从实时或已在末尾时按 ▶：从第 1 步开始。现在 `pause()` 把光标停在最后一步，导致“无可播放”。
- 固定步长，每步约 600 ms，可选 1× / 2× / 4×；不按真实时间间隔（步间可能隔数分钟）。间隔下限约 300 ms（每步都会重算根会话和子会话，跑 `session-runtime-perf` 测试）。
- 播到末尾：停在最后一步，保持回放态，不自动切回实时。
- 播放中拖动进度条：从新位置继续。`goLive` 和卸载时清除定时器。
- 键盘：空格播放/暂停，← → 单步。
- 点日志行：跳到该步（当前行高亮已有）。

### 2. 会话日志（行高不变，仍是 `clamp(88px, 13.5cqh, 176px)`）

- 标题改为右上角角标「日志 · N ⤢」，内边距 `p-4` → `p-3`，行距收紧。88 px 时可显示约 3 条。
- ⤢ 打开浮层：绝对定位，盖在中部区域上方，约 60% 高，不参与网格。支持筛选「全部 / 出错 / 子代理」，Esc 关闭。
- 浮层要显示全部事件，所以要放开 `recentEvents` 的 60 条上限，或只对浮层单独放开。
- 不提高日志行的最小高度：E2E 要求约 600 px 的框架不出现滚动，现在只剩约 30 px 余量。

### 3. 思考框

- 字号 12 → 11，行距约 1.65 → 1.4。同样高度从约 4 行变成约 6 行。
- 保留摘录，并提供明确的「展开」入口看全文。

## 第二批：回环航道（替换中部运行树的子代理卡片和回填框）

示意：[runtime-m4-loop-mockup.html](runtime-m4-loop-mockup.html)（可播放 21 步）。阶段看板方案已放弃，不保留为备选。

### 4. 布局

- 主代理栏（上方）：代理名、模型、请求序号，加一句当前在做什么，例如「等待 2 个任务返回」「正在汇总结果」。思考框在它旁边。
- 中部是回环航道：左侧是主代理核心（派发和汇总时外圈转快，等待时转慢），上方是派发航道（待执行），右侧是作业区（执行中），下方是泊位（待取回）。
- 航道总高度固定在框架网格内，不随任务数增长。
- 左栏：去掉子代理列表框，「需要关注」占满左栏，其中的项目可点击，定位并选中对应探针。
- 范围：只显示当前这一轮的任务（从用户最后一条消息起），更早的折叠成「+N 更早的」。

### 5. 动作对应真实事件

- 派发：探针从核心发射进入派发航道。
- 执行：探针在作业区，外圈转动。
- 后台任务完成：停到泊位，黄色信标闪烁（结果就绪、主代理未取）。
- 取回：主代理用 `task_id` 取回时，核心射出牵引光束，把探针拉回并吸收；核心外圈多一个绿点，计数「已吸收 N」。已取回的任务不再占位置。
- 同步任务（`task`）：完成后沿回传航道直接飞回核心，不进泊位。
- 失败变红、等授权变黄并闪烁，都停在原位。

### 6. 槽位与拥挤

- 探针按派发顺序占固定槽位：作业区 12 个、待执行 4 个、泊位 5 个，装不下的合成「+N」。
- 异常任务若落进「+N」，只和最后一个正常探针对调，其他探针不动。
- 探针标签写任务名（`child.description`，截断），悬停显示全名和代理。

### 7. 交接详情

- 点探针，在航道下方显示：交给它什么（哪次请求派发 + 提示词）、返回了什么（大小 + 摘要）、在哪次请求取回、过程（工具调用数、用时、打开子会话）。可展开看全文。
- 详情跟随选中的任务；回放时跟随光标更新。光标在派发之前时显示「此时尚未派发」。
- 状态栏计数分开写：「子代理 N（运行 n / 阻塞 m）」。

### 8. 减少动态效果与性能

- 系统开启「减少动态效果」时，所有动画停止，只保留位置和颜色。
- 动画只用 SVG + CSS transform；同时转动的外圈不超过 12 个；面板不可见时暂停动画。

### 9. 配色：终端 HUD（用户选定）

- 运行视图固定使用深色海军蓝底，不跟随 VS Code 主题（与 M3 现状一致：M3 也是写死的深色）。
- 底色与线：page `#0b0e14`、bg `#141821`、panel `#181d27`、inset `#1e2430`、line `#2c3445` / `#3a4458`、strong line `#4b566d`。
- 文字：正文 `#cdd6e4`、次要 `#8d97aa`、最淡 `#808aa0`（panel 上对比度 4.87）。
- 角色色（冷色 = 正常运转）：主代理 `#6fd3e0` 青、子代理 / 执行 `#7fa6f5` 蓝、思考 / 派发 `#b39ddb` 紫、已吸收 `#8bd49c` 绿。
- 状态色（暖色 = 需要你）：待取回 / 等授权 `#e6c07b` 黄、失败 `#f2787c` 红。暖色只用于这两类状态。
- 克制：线条和正文保持灰色，颜色只出现在角色名、状态标记和动作上；圆角 2px。
- 跨标签页一致性（后续小补丁，可单独做）：轨迹页「子智能体」标签改用同一个子代理蓝。
