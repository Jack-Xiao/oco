## oco 运行视图设计评审（独立评审，只看截图，2026-10-10）

## 1. 总评
宽布局在「谁在做什么」上 3 秒内能答（环上高亮阶段 + 环心卡片 + 工具台），「现在卡在哪」要靠扫环上的小字：顶栏只写「运行中」，k05 里 write 已跑 15 秒没有任何提示；「要不要我插手」在提问态（k08）答得很好，但提问被忽略后红色警报一直持续到 30 分钟后的待命态（k09/k10），反而让人误以为还需要插手。

## 2. 建议清单（按影响排序）
1. [P1] 顶栏状态要说清阶段、对象和已等时长 — 问题：所有 1100 帧顶栏只有「运行中」；k05 工具台 write 已跑 15 秒仍是普通蓝点，k07「思考中 3.1 秒」只藏在模型框里 — 建议：顶栏改为「运行中 · 等结果 15 秒 · write 在跑」「运行中 · 思考 3.1 秒」；同一请求里超过 10 秒还在跑的调用，工具台该行时长变琥珀色，环上「等结果」下写「write 已 15 秒」；若服务端有「等授权」事件则直接走「需要你」黄色 — 代价：小 — 只改显示（授权事件那条除外）。
2. [P1] 提问态把问题、选项、回答入口拆在三处 — 问题：k08/560-k08 问题正文在环心卡片，3 个选项在「你」卡片且被截断，脚注还写「在下方输入框回答（此处不显示）」 — 建议：环心卡片 = 问题 + 3 个选项整行可读，点选项即把编号填入输入框；「你」卡片只留「等你回答 · 已等 6.4 秒」+「去回答 ↓」按钮；选项截断处用 ▸ 展开 — 代价：中（要接输入框） — 不需要新数据。
3. [P1] 忽略提问后的警报态不收敛 — 问题：k09 → k10 过了 30 分钟，「你」卡片仍是红框 + 划线的 3 个选项，环心卡片红框并混入英文原文「The user dismissed this question」，图例把「失败 / 忽略」合并成一个红点 — 建议：按已定方案改 ⊘ 淡色；本轮结束后「你」卡片折叠为一行「待命 · 上次提问已忽略 21:10:27 ▸」，环心卡片改为「第 4 轮已结束 · 等你下一条消息」，服务端原文只进浮层；图例拆成「失败」「忽略 ⊘」 — 代价：小 — 只改显示。
4. [P2] 「带回结果 ↻」节点从不点亮，且与「组装请求」下的「带回 N 个结果」重复 — 问题：j01/k01/k05/k07 该节点一直是灰的，↻ 不在图例里；结果回流用飘动的「← ✓ bash」小签表现（j03/k06），却落在「调工具 / 等结果」之间而不是这个节点 — 建议：让小签落到「带回结果」节点，节点下写「回来 3/4」，把「带回 N 个结果」从「组装请求」下移走；或者去掉这个节点 — 代价：小 — 只改显示。
5. [P2] 三组计数要用户自己对账 — 问题：j03 环上「在跑 2 · 回来 2」、工具台「在跑 1 · ✓2 · ×0」、子代理「作业 1 · 待取回 0 · 已取回 0/1」，用户要心算 2 = 1 工具 + 1 子代理；「派发航道 / 回传航道 / 待取回泊位」是额外术语，空泊位还画了一大块虚线框 — 建议：环上写「等 2（工具 1 · 子代理 1）· 回来 2」；子代理头改「1 在跑 · 0/1 已回」；删掉航道 / 泊位字样，空泊位不画框 — 代价：小 — 只改显示。
6. [P2] 同一数字重复 3–4 次，标题反而被截断 — 问题：j01「第 9 次请求」出现在模型框头、环标题、工具台头 3 处，上下文「6.3万（上次回执）」同时出现在模型框和状态栏；k05 环标题「第 2 次…」为给 ●● 点阵让位被截断 — 建议：「第 N 次请求」只留在环标题；模型框头只写模型名；工具台头只写状态；上下文留状态栏、模型框去掉；点阵去掉或 hover 才显示 — 代价：小 — 只改显示。
7. [P2] 组装请求时环心卡片原样复述左侧「你」卡片 — 问题：k01 同一段用户消息在屏幕上同时出现两次 — 建议：此阶段环心卡片改成打包清单「带上：你的消息 · 计划 4/4 · 上下文 5.1万 · 0 个结果」，正文留给「你」卡片 — 代价：小 — 只改显示。
8. [P2] 「同一命令 1/3…3/3」是好信号但没有升级 — 问题：k06 三次 bash echo doom-loop-probe 只是灰色小签，环与顶栏没有任何「疑似循环」提示 — 建议：同一请求内同命令 ≥3 次时小签变琥珀色「同一命令 ×3」，环上「调工具」下加「疑似循环」 — 代价：小 — 只改显示（计数已存在）。
9. [P3] 浮层固定 520×430，内容只占上四分之一 — 问题：overlay-think / overlay-result / plan 三张下方大片空白；结果浮层翻不到同一请求的其他结果；「回放：按时间估算的进度」是内部术语；两张浮层的关闭 × 样式不一致 — 建议：高度自适应到上限；结果浮层顶部加「← 3/4 →」；文案改「回放中 · 文本按时间比例展开」 — 代价：小 — 只改显示。
10. [P3] 进度条标签格式不统一且会重叠 — 问题：同一段空闲 j03 写「≈ 空闲 10 分 17 秒」、k01 写「≈10分」、k09 写「≈ 空闲 3 小时 45 分」；k06–k08「≈ 空闲 11 秒 · 第4轮」压在红色刻度上；红 / 黄刻度没有图例 — 建议：统一「≈10m17s」短格式，hover 出全文；刻度颜色沿用底部图例并在图例加「刻度 = 失败 / 提问」 — 代价：小 — 只改显示。

## 3. 窄布局（560）
- [P1] 模型框第二行被「模型思考 / 模型输出」两个节点压住，三张（560-j03/k06/k08）都能看到文字重叠 — 模型框改成环上方的单行条「模型 · 等结果 · 6.8万」，或把两个节点的秒数 / 字数标注移到节点下方让出空间。
- [P1] 环心卡片被挤成右侧一整列高框，三分之二是空的，环里只剩标题，「环心 = 此刻在发的东西」的隐喻断了（560-j03/k06/k08） — 环占满宽度、卡片紧贴环下方全宽自适应高度，工具台与子代理再往下按可折叠条堆叠。
- [P2] 空面板仍占整块（560-k08 工具台约 200px 高只写一句「只发了一个提问」），「← ✓ bash」「→ bash echo…」飘签压在环和连线上（560-k06） — 复用宽布局 k01/k06 已有的单行折叠条；飘签改为工具台对应行末的 ↩ 标记，不再浮在环上。
