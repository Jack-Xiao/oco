# oco 实施任务清单

所有任务初始状态均为 TODO。下列目录是归属约定，不代表代码已经创建。证据写入 `docs/evidence/`，架构决定写入 `docs/adr/`，共享状态统一由集成人更新。

## 协作规则

- 未完成前置依赖，最多进行有界调查，不提交假定接口的成片实现。
- 每个任务有唯一负责人；允许负责人把独立检查交给其他 AI，但需要审核其改动和证据。
- 根 `package.json`、锁文件、构建脚本、`packages/contracts/`、上游补丁和 PROGRESS 由集成人维护。其他人需要改动时先交接口变更说明。
- 每个任务交接包含：修改文件、功能行为、实际检查、未执行检查、遗留问题、下一步。
- 文档记录应以当前结果为准；完成复选框必须有对应证据。

## 顺序与并行窗口

```text
T001 服务/环境调查 ─┐
                    ├→ T003 脚手架 → T004 对话接入 → T005 多会话/上下文 → T006 P0 决策
T002 源码/复用调查 ─┘
T006 → T007 连接 → T008 事件与状态 → T009 侧栏 / T010 对话生命周期
T010 → T011 编辑器上下文 / T012 文件与 Diff
T007 + T010 → T013 Agent 管理 / T014 设置
T007 + T008 → T015 诊断
以上集成 → T016 远程/平台 → T017 回归与性能 → T018 打包 → T019 发布候选评审
```

T001 与 T002 可由两个只读调查者并行；T004/T005 紧密耦合，优先同一实施者。

T009 与 T010 在 T008 契约固定后可并行。T011 与 T012 虽可并行，但必须细分 `editor/context/` 和 `editor/diff/` 归属。T013 与 T014 共用管理页时，由同一 UI 集成人维护页面入口和路由，其他人只编辑独立 feature 目录。

## P0：验证首选路线

### [ ] T001 — 实际服务与环境基线

- 依赖：无。类型：只读调查。建议投入：0.5–1 人天，与 T002 可并行。
- 归属：`docs/evidence/environment.md`、`docs/adr/001-service-contract.md`。
- 工作：确认目标服务的来源、版本、所有权、项目目录语义、鉴权、健康与 OpenAPI；确认本地/远程、客户端 OS、配置是否在宿主可访问范围内。
- 可用环境缺失时先记录未知，建立本地测试服务候选；不能称其等价于企业环境。
- 交付：支持矩阵初版、脱敏接口摘要、必须验证的会话/权限/提问/取消/附件/事件操作、操作所有权说明。
- 完成：目标契约有可追溯证据；缺失环境有明确标记及影响。最少本地测试契约可支持 T003/T004；企业和远程缺口继续跟踪，不能被清单勾选掩盖。

### [ ] T002 — 官方 UI 可复用边界

- 依赖：无，随后与 T001 对齐。类型：只读调查。建议投入：0.5–1 人天。
- 归属：`docs/evidence/upstream.md`、ADR-002 的调查部分；最终 ADR 由集成人整合。
- 工作：核实候选 tag 与精确 SHA；追踪 App/Session、Platform、SDK、草稿、路由、资源/Worker、SSE/WS、存储和全局快捷键；调查许可和源码引入方式。
- 交付：功能保留/接管/禁用表、内部依赖图、必要补丁位置、网络路径清单、是否需要终端模块的结论。
- 完成：依据实际源码写明接口存在与限制；不能以桌面端入口行数估算完整适配成本。不得改动邻近的 OpenCode 工作目录。

### [ ] T003 — 可复现脚手架与最小 Webview

- 依赖：T001/T002 有可用本地基线。
- 归属：根构建文件、`apps/extension/` 最小入口、`apps/chat-webview/` 最小入口、`packages/contracts/` 初始信封、固定上游来源、ADR-002。
- 工作：固定包管理/构建版本；建立开发启动、构建、类型检查和相关测试脚本；扩展能在 VS Code 开发宿主打开 Webview；资源经 asWebviewUri。
- 交付：安装依赖及启动文档、锁文件、最小 VSIX/开发宿主启动路径、上游恢复与补丁步骤。
- 完成：从干净检出/副本可重建；产物不引用作者本机路径；扩展运行不要求终端有 Bun；源码许可证得到保留。
- 注意：Git 初始化可在本任务开始时执行；不配置远程、不创建发布、不修改全局 Git 设置。

### [ ] T004 — 官方对话到真实服务的纵向接入

- 依赖：T003。
- 归属：`apps/chat-webview/`、适配层初版、宿主桥初版、必要上游补丁、ADR-003 初稿。
- 工作：挂载官方界面；绑定一个真实会话；实现被用到的请求/流/取消路径；测试工具结果、权限和提问；处理资源/CSP/Worker 错误。
- 完成：A01/A02/A04/A05/A06 对应的 P0 子集有证据；服务认证不进入持久化前端数据；响应确实增量显示，停止确实到达服务端。
- 禁止：用完整缓冲响应模拟流、用固定回答模拟服务、仅隐藏报错功能后声称完整兼容。

### [ ] T005 — 三会话、草稿与最小上下文原型

- 依赖：T004。
- 归属：对话嵌入入口、宿主 panel registry 原型、最小 editor context、草稿存储适配。
- 工作：打开三个会话，重复点选去重；验证不同草稿、模型/Agent、权限和回复归属；加入未保存代码；完成图片字节链路；隐藏、恢复、重载和中断恢复；尝试远程流式连接。
- 完成：核心多会话用例通过；列出连接数、缓存和全局状态隔离结果；明确临时的完整 App 实例成本。远程缺失按 BLOCKED 标记。
- 交付：`docs/evidence/p0-spike.md`，含补丁清单、运行记录和未解决问题。

### [ ] T006 — P0 架构决定和重估

- 依赖：T001–T005 的实验结果。
- 归属：ADR-004、PLAN/ARCHITECTURE/TASKS/PROGRESS。
- 工作：对照门槛选择继续、限时修复或替代；固定源码、嵌入方式、传输、状态所有权；调整后续工作量与支持范围。
- 完成：结论能由证据支持；没有把“有接口”写成“已运行”；决定后的任务和契约一致。满足门槛后无需为普通实现再申请确认。

P0 合计以 3–5 人天为初始时间盒，各子任务用时由实验结果记录，不强行把未完成项目塞入既定日期。

## P1：可用客户端

### [ ] T007 — 连接与自有进程管理

- 依赖：T006。
- 归属：`connections/`、`packages/opencode-adapter/` 连接部分、连接契约。
- 工作：attached/managed、可执行文件路径、认证保存、健康/能力、错误状态、工作区信任、多根工作区映射和进程退出行为。
- 完成：A01/A12/A13 通过；坏路径/端口占用有明确错误；外部服务从不被扩展清理；断线不无限重启；拥有多个面板不重复启动服务。

### [ ] T008 — 事件、状态与恢复协调

- 依赖：T007。
- 归属：`sessions/`、适配层流/快照部分、相关契约。
- 工作：会话缓存、事件路由、排序与去重、有界队列、面板 epoch、重连同步、发送结果未知、真实取消和权限过期。
- 完成：重复/乱序/断流/迟到响应/队列溢出夹具通过；真实断线恢复有证据；无游标时快照与增量衔接正确；写请求不会被无条件重发。

### [ ] T009 — 原生会话侧栏

- 依赖：T008 与 panel 打开契约。
- 归属：`views/sessions/`；由集成人合并扩展贡献点。
- 工作：连接/工作区分组、创建、搜索、重命名、运行/等待权限/失败状态、打开或聚焦。
- 完成：分页或长列表策略符合实际 API；没有把其他目录会话误归当前项目；新建会话身份回填正确；列表与实际任务状态一致。
- 归档/删除：不属于默认必做项；如纳入，需要能力证据、作用范围和交互确认，不能用本地删除列表项冒充服务操作。

### [ ] T010 — 正式单会话视图与生命周期

- 依赖：T008；与 T009 可并行。
- 归属：`panels/`、`apps/chat-webview/`、对话相关上游补丁。
- 工作：从原型收敛嵌入模式；会话路由归宿主；草稿/附件恢复；模型/Agent/命令；通知归属；未知消息/工具类型兜底；主题和键盘操作。
- 完成：A02–A09 相关部分通过；同会话只有一个面板；会话消失/服务不可达有可恢复界面；无失效导航按钮；不用 retainContextWhenHidden 代替持久化。

### [ ] T011 — 编辑器上下文与附件

- 依赖：T010 和草稿添加契约。
- 归属：`editor/context/`、对应消息契约；聊天页面由其负责人接线。
- 工作：选区/当前文件、未保存缓冲、来源与范围、明确目标会话、图片和文件大小限制、字节编码、本机/远端来源区分。
- 完成：A03/A07/A11 通过；验证服务实际收到内容而非仅出现缩略图；不会自动发送；旧草稿和新内容不互相覆盖。

### [ ] T012 — 文件跳转与可信 Diff

- 依赖：T010、服务 Diff 能力证据。
- 归属：`editor/files/`、`editor/diff/`。
- 工作：文件/行列映射、远端 URI、只读差异文档、base/head 来源标签、无快照降级。
- 完成：A10 通过；处理不存在文件、二进制和路径越界；Git 已有改动不会被标成该会话独占成果；不提供无正确前像的回滚。

## P2：管理与体验

### [ ] T013 — Agent 定义管理

- 依赖：T007/T010、T001 确认配置读取/写入/刷新能力。
- 归属：`agents/`、`views/agents/`、`management-webview/features/agents/`。
- 工作：列表、来源/范围/覆盖关系、新建/复制/编辑、原文入口、模型/提示词/权限表单、冲突检测、生效确认。

### [ ] T014 — 设置与管理页外壳

- 依赖：T007/T010；和 T013 先固定配置操作契约。
- 归属：`settings/`、`management-webview` 外壳及 settings feature；根配置贡献点由集成人维护。
- 工作：VS Code 原生设置承载连接和 UI 偏好；管理页承载复杂 Agent 操作；展示有效范围、错误和待生效状态。

### [ ] T015 — 诊断、错误和操作体验

- 依赖：T007/T008；可与其他 P2 任务并行。

- 完成：A16 通过；可定位问题且不包含秘密/消息全文；无无限重试、重复弹窗或静默失败。

## 通用完成标准

一个实现任务只有同时满足以下条件才可标 DONE：

1. 行为与该任务验收一致，相关错误路径已覆盖。
2. 必要构建、类型检查、契约或状态测试通过；UI/网络能力有相应真实证据。
3. 只修改自己的文件，公共修改经集成人整合；没有覆盖他人工作。
4. 文档、状态和实际代码一致，未执行项没有被写成通过。
5. 本次运行命令、环境版本和结果已记录，日志已脱敏。
