    DMC-OCO-A-02-00受控语言速读卡参照 ASD-STE100 写法

    用受控语言说清 oco

    ASD-STE100 是航空维修文档的受控语言。本卡采用它的几条规则。中文版是“接近 STE”的写法，不是规范认证。

    ASD-STE100 is a controlled language for aerospace maintenance texts. This card uses its main rules. The English text is close to STE. It is not a certified STE text.

    • 一句一事
    • 主动语态
    • 一词一义

    TASK 1认识三层Identify the three layers

    1. oco 是 OpenCode 的 VS Code 客户端。oco is a VS Code client for OpenCode.
    2. oco 不执行任务。服务执行任务。oco does not do the tasks. The server does the tasks.
    3. Webview 显示对话界面。The webview shows the chat interface.
    4. 扩展宿主持有连接和密码。The extension host keeps the connection and the password.
    5. 服务保存会话的事实。The server keeps the session data.

    TASK 2发送一个请求Send a request

    1. 网页把请求发到 oco.bridge。The web page sends the request to oco.bridge.
    2. 桥把请求变成一条消息。The bridge changes the request into a message.
    3. 宿主用策略检查这条消息。The host examines the message with the policy.
    4. 策略通过后，宿主加上认证。If the policy accepts the message, the host adds the authentication.
    5. 宿主把事件流逐块发回网页。The host sends the event stream back to the page, one part at a time.

    TASK 3停止与重新加载Stop and load again

    1. 要停止请求，网页发送 fetch.abort。To stop a request, the page sends fetch.abort.
    2. 宿主按请求号中止请求。The host stops the request that has this id.
    3. 面板重载时，宿主分配新的 gen。When the panel loads again, the host gives a new gen.
    4. 宿主丢弃旧 gen 的回复。The host discards each reply for an old gen.

    TASK 4遵守边界Obey the limits

    1. 警告远程时，127.0.0.1 是远端主机。WARNINGIn a remote window, 127.0.0.1 is the remote host. It is not your computer.
    2. 注意oco 不停止 attached 服务。CAUTIONoco does not stop an attached server. Do not expect it to.
    3. WebSocket 已禁用。终端不可用。WebSocket is disabled. The terminal is not available.
    4. 网页不能读任意文件或执行命令。The page cannot read a file or run a command directly.

    桥上的消息类型Message types on the bridge

    Webview → 宿主host作用Function
    hello新文档报到，领取 gen。A new document starts. It gets a gen.
    fetch.request发出一个 HTTP 请求。Sends one HTTP request.
    fetch.abort停止一个请求。Stops one request.
    store.op读写宿主存储。Reads or writes host storage.
    blob.op存取附件字节。Puts or gets attachment bytes.
    ui · draft.ack · ready界面动作、草稿确认、就绪。UI action, draft receipt, ready.
    宿主Host → Webview作用Function
    welcome回复 hello，给出 gen。Replies to hello. Gives the gen.
    fetch.head · chunk · end响应头、数据块、结束。Response head, data part, end.
    fetch.error策略拒绝、网络失败或已中止。Policy refusal, network failure, or abort.
    store.result存储操作的结果。The result of a storage operation.
    draft.insert把选中的代码加入草稿。不发送。Adds selected code to the draft. Does not send it.
    connection · navigate连接状态；切换到另一个会话。Connection state. Go to another session.
