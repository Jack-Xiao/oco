## 先固定的小接口

先固定以下小接口，再并行实现侧栏、窄布局主题和测试：

1. connection summary：连接标识、名称、可见状态、错误和重连状态。
2. session list：会话标识、标题、目录、更新时间和当前状态。
3. session status：运行中、空闲、错误、等待权限、等待提问等状态。
4. open-session：打开已有会话，或聚焦已经打开的编辑器组。

公共 host 与协议由集成人串行维护，避免并行修改造成契约漂移。
实现应复用现有接口，不以新增服务或替换传输层解决局部问题。

- 窄栏中的权限按钮必须支持真实 pointer click。
