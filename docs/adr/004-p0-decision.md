## 决定

**继续首选路线**：VS Code 原生外壳 + 固定官方 v1.18.33 源码 + 宿主桥。P0 未发现需要广泛重写官方状态层的阻断项，补丁目前 1 个（+20 行），其余适配在构建配置与宿主侧完成。

P1 可以在本地开始；**远程门槛未通过**，在 T016 前不得宣称 Remote-SSH 支持。

## P1 必须先解决（按优先级）

1. **单会话嵌入模式**（T010 首项）：按面板隔离 tabs/布局持久化，或禁用官方内部标签栏与会话导航，确保一个 VS Code 标签页只呈现其绑定会话。预计 1–2 个小型上游补丁。
2. 宿主存储逐 key 读写与作用域（global/workspace）划分（T008/T010）。
3. 显式禁用终端入口，避免悬空 WebSocket（T010）。
4. 标签标题同步、主题跟随 VS Code、加载中状态（避免“Select an agent and model”）（T010）。
5. 事件订阅共享与重挂载成本（T008）：P0 实测每次显示重挂载约 1.1–1.5 s、每可见面板约 +350 MB。

## 重新估算

- P0 实际：约 1 个工作日（含两次运行时问题排查）。
- P1：由 8–12 人天调整为 **9–13 人天**（+1 用于单会话模式与存储作用域）。
- P2、P3 暂不变；总计 **24–38 人天**。企业服务、远程主机、Windows 设备的可用时间不在估算内。
