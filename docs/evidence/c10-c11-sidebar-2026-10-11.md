## 产品缺陷
1. 自由文本框不显示: opencode 1.18.33 的 GET /question 不返回 question.custom（服务端默认允许自定义答案），侧栏按 `Boolean(currentQ.custom)` 判定，缺省被当作 false，选项题没有 [data-question-input]。复现: 提示 "Use the question custom tool ..."，点 Answer，表单只有选项按钮。位置 apps/extension/media/sessions-list/index.js `showCustom`（约 724 行）。建议 `custom !== false`。
2. todo 徽标永不出现: GET /session/:id/todo 返回 [{content,status,priority:"medium"}]（无 id、priority 为字符串），但 session-store.ts `setTodo` 丢弃没有 id 的条目，且 priority 只接受 number，结果 todo 全部被过滤，行无 [data-todo]。复现: 对会话发 "Use the todowrite tool to plan: write spec; build it; ship it"，API 返回 3 项，侧栏行无徽标（失败截图见 c11 run 目录 5-todo-missing.png）。建议无 id 时用 index 兜底并放宽 priority 类型。（todo.updated 事件未单独抓包，推断同源）
